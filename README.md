# 商品图片工作台

一个用于跨境电商商品图生产的内部网站。上传一张或多张商品参考图，选择目标平台后，系统先生成白底基础图，再按需生成精修白底图、生活场景图、真人使用图、英文功能图、细节特写图和包装与清单图。

## 这份项目包含什么

- `public/`：网站首页和生成画布。
- `server.js`：本地服务、图片任务、下载和失败重试。
- `rules.json`：Amazon、AliExpress、Mercado Libre、Temu、Shopee、SHEIN 的尺寸、首图限制和图片风格规则。
- `scripts/cutout.py`：本地 BEN2 商品抠图和白底图生成。
- `scripts/codex-image-task.js`：将平台规则、商品参考图和用户要求提交给本机已登录的生图服务。

用户上传的图片、生成结果、模型权重、虚拟环境和日志不会提交到 GitHub，避免仓库过大或泄露内部素材。新电脑首次运行时会重新下载 BEN2 模型。

## 新电脑安装要求

请使用 Windows 10/11，并提前安装：

1. [Node.js LTS](https://nodejs.org/)，安装后在命令行输入 `node --version` 应能看到版本号。
2. Python 3.10 或 3.11，安装时勾选 **Add Python to PATH**。
3. Codex 桌面端或 Codex CLI，并在该电脑上完成登录。展示图生成会使用这台电脑已登录的生成能力。
4. 首次安装模型需要联网，并建议预留至少 5 GB 磁盘空间。若电脑只有 CPU，白底图仍可用，但处理会较慢。

## 第一次启动

1. 下载或克隆本项目到任意英文或中文文件夹。
2. 双击 `setup-first-run.cmd`。
   - 脚本会创建 Python 环境、安装 BEN2 及其依赖，并下载白底图模型。
   - 首次下载时间取决于网络和电脑配置，完成后无需重复执行。
3. 双击 `start-studio.cmd`。
4. 浏览器打开 `http://127.0.0.1:5177` 后即可使用。

之后只需要双击 `start-studio.cmd`。保持弹出的黑色窗口打开，网站才会持续运行；关闭该窗口即可停止网站。

## 使用流程

1. 上传至少一张商品参考图；建议同时上传正面、侧面、细节、包装或配件图。
2. 选择销售平台与商品品类。
3. 进入生成画布，点击“先生白底图”。每张参考图都会生成对应的白底图。
4. 选择需要的展示图类型并生成。生活图、真人图、英文功能图、细节图和包装图可以多选。
5. 在画布中查看图片，使用“下载”“打开原图”“重新描述”或失败重试入口完成交付。

## 规则和内容边界

- 白底图按目标平台规格输出；不同平台的尺寸和首图限制在 `rules.json` 中维护。
- 英文功能图只有在用户补充卖点时才使用对应卖点；未补充时仅描述图片中可见的事实，不应将结果视为参数、认证或性能承诺。
- 细节特写图会要求一张图内组合 2–4 个真实可见细节。
- 包装与清单图有包装/配件参考时才可作为真实清单表达；没有参考时只会生成概念包装图，不代表实际配件数量。

## 常见问题

### 白底图提示“本地 BEN2 尚未就绪”

请先运行 `setup-first-run.cmd`，等待脚本完整结束后再启动网站。

### 展示图生成失败

确认本机 Codex 已登录，并保持网络可用；随后点击失败图片的“重新生成”。展示图生成通常比白底图慢，单张可能需要 1–2 分钟。

### 端口已被占用

关闭之前启动的网站窗口，或在任务管理器结束旧的 `node.exe` 进程后再双击 `start-studio.cmd`。

## 开发启动（可选）

在项目根目录运行：

```powershell
node server.js
```

然后访问 `http://127.0.0.1:5177`。
